# Selected-publication images

These three author-supplied images were provided for David Maestas's personal
website in `Website_Publication_Images.zip` on November 3, 2026. The original ZIP
is preserved outside this repository. PNGs here are byte-identical to the supplied
files. Lossless WebP encodings preserve all decoded RGBA pixels, including RGB
values in transparent pixels. No cropping, recoloring, retouching, compositing,
or scientific-content changes were made. All labels and scale bars are retained.
CSS scales the complete images; full-resolution PNG links are provided.
